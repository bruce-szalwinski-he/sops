# Internal Homebrew Tap Setup

## Repository Structure

Create a new repository: `hotelengine/homebrew-internal-tools`

```
homebrew-internal-tools/
├── README.md
├── Formula/
│   └── (for CLI tools as formulas - not needed for SOPS)
└── Casks/
    └── sops-hotelengine.rb (will be auto-generated by GoReleaser)
```

## Initial Setup Commands

```bash
# Create the repository
gh repo create hotelengine/homebrew-internal-tools --private --description "Internal Homebrew tap for HotelEngine tools"

# Clone and set up initial structure
git clone https://github.com/hotelengine/homebrew-internal-tools.git
cd homebrew-internal-tools

# Create initial structure
mkdir -p Casks Formula
echo "# HotelEngine Internal Tools Homebrew Tap" > README.md
echo "" >> README.md
echo "This tap contains internal tools for HotelEngine development." >> README.md
echo "" >> README.md
echo "## Installation" >> README.md
echo "" >> README.md
echo "\`\`\`bash" >> README.md
echo "# Add the tap" >> README.md
echo "brew tap hotelengine/internal-tools" >> README.md
echo "" >> README.md
echo "# Install tools" >> README.md
echo "brew install --cask sops-hotelengine" >> README.md
echo "\`\`\`" >> README.md

# Commit initial structure
git add .
git commit -m "Initial tap structure"
git push origin main
```

## GitHub Token Setup

Create a GitHub token with the following permissions for the `HOMEBREW_TAP_GITHUB_TOKEN` environment variable:
- `repo` (full repository access)
- `workflow` (if using GitHub Actions)

Store this token in your GitHub repository secrets as `HOMEBREW_TAP_GITHUB_TOKEN`.
